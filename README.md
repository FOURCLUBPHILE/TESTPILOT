# TestPilot

Automated website testing framework built using Selenium and Python.

## Features
- Automated login testing
- Invalid login testing
- PASS/FAIL validation
- Screenshot capture on test failure
- Browser automation using Selenium

## Technologies Used
- Python
- Selenium
- Chrome WebDriver
- WebDriver Manager

## Test Cases
1. Valid Login Test
2. Invalid Login Test
3. Login Validation Test

## Project Structure

TESTPILOT/
│
├── tests
├── screenshots
├── README.md
└── requirements.txt

## How To Run

Install dependencies:

```bash
pip install -r requirements.txt
```

Run tests:

```bash
python tests/login_test.py
```
